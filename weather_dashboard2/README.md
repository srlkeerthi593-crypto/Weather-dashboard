# Block vs District Weather Dashboard
Anand · Kheda · Mahisagar, 2021–2023

Run: `pip install -r requirements.txt` then `streamlit run app.py`
Deploy: push to GitHub, then share.streamlit.io, main file `app.py`.

- `app.py` – the dashboard (4 tabs)
- `helpers.py` – data loading, calculations, maps, colours
- `data/` – your 3 Excel files + `blocks.geojson` (block outlines, DataMeet public data)
- `results/` – your result charts
